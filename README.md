# Skin Shift (Forge 1.21.1)

**Зажми V** — открывается колесо выбора скина (скины берутся из папки `skinshift/skins`
в корне игры). Прокручивай колёсиком мыши или стрелками ← →, отпусти V на нужном пункте —
применится: руки поднимаются к груди → вокруг игрока крутится эффект частиц → скин
попиксельно «проявляется» на выбранный. Видно всем игрокам на сервере. Esc — отмена без
применения.

**Отдельная клавиша** (по умолчанию N, тоже меняется в Настройки → Управление → Skin Shift)
открывает настройки: стиль частиц (вихрь / спираль / взрыв) и их цвет из палитры.

## Своя папка со скинами
При первом запуске клиента мод сам создаёт папку:

```
<корень игры>/skinshift/skins/
```

(рядом с `saves`, `resourcepacks` и т.д. — то есть ровно там, где ты просил). Просто
закинь туда PNG-файлы 64×64 в обычном формате скина Minecraft — каждый файл появится
отдельным пунктом в колесе, имя пункта берётся из имени файла. Файлы неправильного
размера или битые PNG мод тихо пропускает. Папка пересканируется при каждом открытии
колеса, так что новые скины подхватываются без перезахода.

## Как получить .jar через GitHub
1. Создай пустой репозиторий на GitHub.
2. Загрузи в него **содержимое** этой папки (чтобы `build.gradle` и папка `.github` лежали
   в корне репозитория). Папка `.github` скрытая — при загрузке через сайт перетащи её тоже.
3. Открой вкладку **Actions** → workflow **Build mod** запустится сам (или нажми
   *Run workflow*).
4. После зелёной галочки внутри запуска, внизу в разделе **Artifacts**, скачай
   `skinshift-jar` — внутри будет `skinshift-1.0.0.jar`.
   Если красный крестик — открой лог шага **Build** и пришли мне текст ошибки, поправим.

## Что нового в этой версии
* Скины больше не вшиты в мод — загружаются из папки `skinshift/skins` в рантайме.
* Колесо выбора по зажатию V вместо простого переключателя туда-обратно.
* Отдельный экран настроек (клавиша N): 3 стиля частиц и 8 цветов на выбор.
* Выбор синхронизируется по сети — другие игроки видят и новый скин, и твой эффект.
